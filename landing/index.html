The thesis

Off-the-shelf valuation tools overvalue Latam SMEs by 30–60%.

They apply US discount rates to Colombian and Argentine businesses. This engine does the opposite — and lets you defend the DCF in front of any investment committee.

Country Cost of Equity WACC (β=1.2, 30% D/V)
🇺🇸United States 13.13% 10.73%
🇨🇴Colombia 15.54%+2.41 pp 14.27%+3.54 pp
🇦🇷Argentina 25.07%+11.94 pp 26.33%+15.60 pp

Apply the US WACC to an Argentine SME and you're handing your client a number that will fail any competent investment committee. The country risk premium alone accounts for 30–60% of valuation differences.

What it does

Five things, done rigorously.

🌎

WACC with country risk premium

ke = rf + β·ERP + CRP for Colombia and Argentina, calibrated against current EMBI spreads, Damodaran ERPs, and central-bank lending rates.

⚡

Vectorized Monte Carlo DCF

100,000 iterations in ~120ms (vs minutes in Excel). Triangular distributions for early-stage businesses where normal isn't justifiable.

📋

Business Model Canvas schema

JSON Schema 2020-12 for the 9 Osterwalder blocks, validated with Pydantic. Build the CANVAS from the API, export to PDF.

📊

Macro data layer

Banrep, DANE, BCRA, INDEC snapshots in data/macro/. Refresh quarterly, provenance documented per field.

🔌

Open REST API

Four endpoints: POST /valuation/dcf, POST /valuation/wacc, GET /valuation/macro/{country}, GET /health. Free tier up to 100 valuations/month.

🧪

Auditable by design

Every constant is a named parameter, not a cell reference. Original VBA macros from the workshop preserved in docs/vba_original/ for credit and audit.

Try it

From pip install to a defensible DCF in 30 seconds.

$ pip install latam-valuation-engine
from latam_valuation_engine import (
    wacc_from_defaults, Country
)
from latam_valuation_engine.monte_carlo import (
    MonteCarloConfig, run_monte_carlo
)
import numpy as np

# WACC for a Colombian retail business
wacc = wacc_from_defaults(
    Country.COLOMBIA,
    beta_unlevered=1.2,
    debt_to_total_capital_pct=30.0
)
# → WACC: 14.27%   Ke: 15.54%

# 10,000-iteration DCF
flujos = np.array([50, 70, 95, 120, 150])  # M COP
cfg = MonteCarloConfig(
    n_iterations=10_000,
    wacc_pct=wacc.wacc_pct,
    inversion_inicial=300.0
)
result = run_monte_carlo(flujos, cfg)
print(f"VPN: {result.vpn_mean:.1f}M COP")
print(f"P(VPN>0): {result.prob_exito_vpn_positivo():.0%}")
output

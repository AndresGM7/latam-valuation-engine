# Workshop Original: "Trascender — Emprendimiento y Finanzas"

El PDF original del workshop (33 páginas, ~28 MB) NO se incluye en este
repositorio por su tamaño. Está disponible para consulta privada.

## Contenido extraído (resumen)

El workshop cubre los 4 módulos del programa "Ser, Hacer y Crecer":

1. **Motivación/Ideación** — Mapa mental de felicidad, ciclo del
   emprendimiento, Q-storming, brainstorming.

2. **Planeación** — Entorno económico y poblacional, pirámide
   poblacional (DANE), mapa de empatía, mapa de valor, benchmarking.

3. **Estructuración** — Prototipado de bienes/servicios, **Business
   Model Canvas** (Osterwalder), beneficio empresarial, estados
   financieros, análisis vertical y horizontal, indicadores
   financieros (liquidez, rentabilidad, endeudamiento).

4. **Viabilidad y Estrategia** — Estudios de viabilidad (jurídico,
   mercado, financiero, ambiental), planeación financiera, VPN,
   escenarios de valoración, análisis de sensibilidad, fuerzas de
   Porter aplicadas al CANVAS, estrategia.
